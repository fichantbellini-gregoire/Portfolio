Projet

Présentation du projet

Ce projet était dans le cadre d'une Situation d'apprentisage et d'évaluation (SAE) dont son but était de nous faire acquérir la capacité concevoir, gérer, administrer et exploiter les données de l’entreprise et mettre à disposition toutes les informations pour un bon pilotage de l’entreprise. Le projet en lien avec cette compétence était d'étudier puis de réaliser une base de données pour une application de comparateur d'offres d'élétricité.

Déroulé du projet

Dans l'étape 1, on devait réaliser le diagramme de classe de notre base de données grâce à l'aide des documents annexes. On a ainsi utilisé le logiciel Visual Paradigm, un logiciel qui permet de faire des diagrammes de classes. On a utilisé la version en ligne car elle offrait le possibilité de travailer en colllaboration, vu que ce projet était en binôme. On l'a réalisé en utilisant le language Tutorial D sur le logiciel Rel. Bilan du projet

Ce projet m'a permis de découvrir l’implémentation d’une base de données. Il m'a fait découvrir les différentes étapes à faire pour réussir une bonne implémentation d'une base de données. J'ai obtenu des bases en Tutorial D et j'ai aussi découvert de nouveaux logiciels très intéressant. Je le considère comme partiellement réussi car même si nous avons parfaitement implémenté notre base de données, le diagramme de classe qu'on avait effectué au préalable était loin de ce qui était attendu. Je pense cependant que j'ai tout de même validé cette compétence.
